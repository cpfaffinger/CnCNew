## Non-negotiable rules (unchanged, see `CLAUDE.md`)

- Unknown keys/modules/enums/references never fall back silently to defaults; every case is explicit, counted, documented and secured against `baselines/compatibility.json`. New actions/conditions: enter in `ScriptCoverage` (test `ScriptSupportTableIsConsistent`), cite the source function (`ScriptActions.cpp`/`ScriptConditions.cpp`, never wholesale), test in `tests/CnCNew.Simulation.Tests/Tests.Scripting*.cs`, line in `SCRIPT-ENGINE.md` §4/§5 (deviations in §8). Something that the simulation does not evaluate is **recorded** (`ScriptSupport.Recorded`) or missing, never "executed".
- Determinism: sorted collections, no wall-clock time, no `float`/`double`, no `Random.Shared`; `SourceRules` applies to the whole script VM. Every new script state belongs in `ScriptEngine.Describe`/`Load` (write only if not empty, otherwise hashes of existing runs change); the continuation test (`MissionScenario.VerifyContinuation`) catches what is missing.
- `TreatWarningsAsErrors=true`; 21 explained warnings with a clean build (see `CLAUDE.md`), every other one is an error.
- Snapshot/replay/mission formats: incompatible changes increase the respective version (`WorldSnapshot` 7, replay 7, `MissionSnapshot` 2, `CommandTypes.Version` 10); older ones are rejected with a clear message.
- Third-party code only to be read, not copied; cite every ported action/condition individually with file and function.
- Always re-measure inventory numbers, never adopt them from this document.
- Work only locally, no remote, push nothing; several commits each closed in subject matter; working tree clean at the end; at the end write and commit `docs/handoffs/HANDOFF-PHASE13.md`.
- **Preserve line endings:** check per file with `git ls-files --eol <datei>` (not with `grep`/counting `\r` in this environment): `README.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, `docs/IMPLEMENTATION-PLAN.md` are CRLF, the other documents and the whole source code LF.
