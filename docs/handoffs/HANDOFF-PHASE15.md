If a gap remains unfixable (no patched package), it is justified individually with its risk – not suppressed wholesale (`NuGetAudit` stays on).
2. **Missing model parts (item 2 of the findings).** First prove, then fix: a reproducible comparison image of an affected building (e.g. barracks, command centre) with `--smoke-test --capture … --model-path …` and the same scene in wireframe/without back-face culling; mesh-by-mesh balance of the model (which `Mesh`/`HLOD` sub-objects of the W3D are visible in the original and which the client draws: `W3dAssetLibrary`, `ObjectRenderVertexBuilder`, `W3dStrideScene`). Checkpoints: `HLOD` proxy/sub-objects and LOD levels (draw only the highest level), visibility per `ModelConditionState` (`ShowSubObject`/`HideSubObject` from the object definition), two-sided meshes and back-face culling, triangle winding after coordinate conversion, pass flags/material passes (`docs/W3D-MATERIALS.md`), textures with alpha. The result is a table "model × part present/drawn" over **all** building models of the retail data (audit in `CnCNew.PresentationTool object-audit`: drawn/total triangles per model, meshes without a pass, discarded meshes with a reason) – no model may lose parts silently.
3. **Bones, animations and states (items 3 and 4).** (a) Bone/pivot transformation: parent chain, conventions (W3D is Z-up, rotation as a quaternion, pivot transformations relative to the parent), rest pose against frame 0 of the animation, skinning (`skinned=4` in the mission – only few objects use it); goal: bulldozer, tanks, vehicles in general stand correctly (wheels at the bottom, turrets/barrels in the right place). (b) State selection: `ModelConditionState` per entity (movement, attack, damage `DAMAGED`/`REALLYDAMAGED`, construction/`ACTIVELY_BEING_CONSTRUCTED`, upgrade, container states): which states the simulation delivers today (`ConditionDeriver`, `ModelConditions`) and which the original additionally derives from vehicle draw modules (`W3DTruckDraw`: wheels turning/suspension/tyre tracks, `W3DTankDraw`: treads, `W3DOverlordAircraftDraw`); turrets: turret rotation and pitch (`TurretBone`/`Turret` data of the `AIUpdate` modules) instead of the rest pose. (c) Play animations per state (`AnimationMode`, speed, transitions); keep counting missing animations. Result: audit numbers (`MissingAnimations`, states without animation) and one visual-check checklist each (bulldozer, Crusader, Raptor, Comanche, Chinook, barracks under construction/damaged).
4. **Map object angles (item 5).** Check the angle of the `ObjectsList` (type, unit, sign, offset; reference: `MapObject` parser and `Object::setOrientation`/`getTransformMatrix` in the EA sources) with several map objects against the model forward axis: roads, fences, buildings with a recognisable front, vehicles of the starting line-up, waypoints/scripts with an angle. Verified by measured values (angle in the file vs. orientation in the client), not just by eye; extend `MapTool audit` by angle statistics. The simulation reads the same angles (combat, building site, orientation at spawn): every correction at the source, not only in the rendering – and because of the hashes re-measure the `CLAUDE.md` reference values (reference match, stress test, map script hashes) and justify the change.
5. **Fog of war (item 6).** In the original one sees in the fog (grey, "explored" state) terrain **and** known buildings (remembered structures), never vehicles/units; in the demo building models appear without terrain. Check: how `FrameProjector` determines visibility and `ShroudedStatus`, how the fog layer draws the shading map (`Shroud`, three states unexplored/explored/visible) onto the terrain, whether the object layer draws remembered buildings from the **last seen** state (ghost objects) instead of from the current one, whether depth/order of objects and fog are right and whether unexplored areas hide objects. Result: comparison images (unexplored, explored, visible) and a test that checks "no object drawn in unexplored territory; remembered buildings only in the explored state".
6. **Checking tool for the visual check.** For all four rendering items a reproducible capture set (`--capture`, `--look`, `--angle`, `--pitch`) with a fixed scene per finding, stored in the scratchpad (not in the repo), and a checklist in `docs/CLIENT-OBJECTS.md` that the human can tick off in two minutes. ## Non-negotiable rules (unchanged, see `CLAUDE.md`)

- Unknown keys/modules/enums/references never fall back silently to defaults; every case is explicit, counted, documented and secured against `baselines/compatibility.json`. A discarded mesh, a missing animation, an unknown state is counted and named in the audit, never silently passed over.
- Determinism: simulation changes (item 4) only with a justified hash change; rendering changes do not influence the simulation (layers stay separate: Stride types only in `CnCNew.Client.Stride`; the presentation reads snapshots and writes only typed commands).
- `TreatWarningsAsErrors=true`; re-measure the warning count after item 1 (target: 11 with a clean build), every other new warning is an error.
- Versions: incompatible changes increase `WorldSnapshot` (8), replay (8), `MissionSnapshot` (2), `CommandTypes.Version` (11).
- Third-party code and original images: EA sources only to be read, not copied; reference images of the original game not into the repo; original assets stay in `.local/`.
- Always re-measure inventory numbers. Local only, no remote, push nothing; several commits each closed in subject matter; working tree clean at the end.
- **Preserve line endings:** per file `git ls-files --eol <datei>`; CRLF in the index have `README.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, `docs/IMPLEMENTATION-PLAN.md`, everything else is LF (`Entity.cs` has mixed endings: in merges take the `main` version and apply hunks by hand). For the CRLF files `pwsh` with `[IO.File]::ReadAllText/WriteAllText` (UTF-8 without BOM); never start scripts with umlauts with Windows PowerShell 5.
- **Background runs always with a bounded timeout**; rebuild Release tools after source changes (otherwise stale numbers); when rebuilding during a run build into another output directory.
