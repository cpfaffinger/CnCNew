# Zero Hour Reforged - a second source of fixes, the work list

Started in Phase 39 (27 October 2026) on the project owner's pointer; the review itself is Phase 40 (`docs/handoffs/HANDOFF-PHASE40.md`, S3-M7). **Zero Hour
Reforged** (`https://github.com/olcayseygan/CnCGeneralsZH-Reforged`, Olcay Seygan and contributors) is EA's released C++ source worked on as a game: a 64-bit
build with a Direct3D 11 renderer, 60 logic steps a second, a skirmish AI of its own, balance changes - and, by its own count, "around sixty" bugs of the
shipped game fixed. Its licence is EA's GPL-3.0 with EA's additional terms (`LICENSE.md` there); this port is GPL-3.0-or-later. As with GeneralsGameCode
(`docs/GGC-FIXES.md`) and the rules of `CLAUDE.md` for foreign code: its code is **read, never copied**; a fix is understood in the original's source, rewritten
for this port and documented with the source places. The list below paraphrases its changelog (`CHANGELOG.md` there, state of 25 October 2026, version 3.4.2);
nothing is quoted from it.

## 1. What a Reforged change can be for this port

Reforged is a game of its own, not a fix layer: most of it changes the game on purpose. Each entry falls into one of these kinds:

| Kind | What it is | What this port does |
| --- | --- | --- |
| A | A defect of the C++ code (uninitialised memory, a save that writes a field twice, a read past an array, a desync of the client) | Nothing to adopt: the port has none of that code. Checked only where the defect shows that the original *behaves* oddly as a result (then kind B) |
| B | The original's logic does something its own data or comments say it should not (a delay computed and thrown away, a flag nothing reads) | The original profile keeps the original's behaviour (Stage 1: the yardstick is the shipped game); the fix is offered behind the rule profile (`GameFix`), like the GeneralsGameCode fixes |
| C | The port itself differs from the original where Reforged found the original's code | A fidelity finding of this port (register `docs/plan/STAGE-1-PORT.md` §3), fixed in the original profile |
| D | A balance, AI, interface or rendering change of Reforged's own design (prices, damage, sight blocked by hills, a new AI, ranks, an interface) | Not adopted; Stage 3 may take an idea as an option of its own design, never as a fix |
| E | Already covered: the same fix taken from GeneralsGameCode, which Reforged also took (`GameFix` 1 to 19, `docs/GGC-FIXES.md` §3) | Named, nothing to do |

## 2. Decided in Phase 39

- **F-06** (a supply truck's dock order overwrites a player's command given in the frame it entered "wanting"): Reforged lists the same thing among EA's bugs.
  The port's behaviour is the original's (`docs/SIMULATION-CORE.md` §53.4) - kind B: a candidate for the rule profile.
- **F-08**: Reforged no longer refunds a whole Red Guard order cancelled after the first soldier left. The original refunds the whole cost
  (`ProductionUpdate::cancelUnitCreate`), and so does this port - kind B (a candidate), not a fidelity defect.
- **F-09**: Reforged opens a factory's doors during the last seconds of the build, so a unit leaves at completion. The original opens them only when the unit
  is finished (`ProductionUpdate::update`), and so does this port since Phase 39 - kind D/B (a design choice that shortens every build), not a fidelity defect.
